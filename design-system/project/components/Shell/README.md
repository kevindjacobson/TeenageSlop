A SHELL row: one command the crew ran, live or finished.

Terminal text in `row`: a glyph, a space, the elapsed time, `BG` in `blue` when backgrounded, then the command clipped to the width. Live rows are `white` with a `green` timer and alternate `▶` and `▷` each frame. Finished rows are `grey` with `●`, `red` with `✕` on a non-zero exit, `■` when interrupted. The last 8 rows show.
