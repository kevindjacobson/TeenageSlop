The LOG: the last three event lines.

Terminal text in `row`. The newest line is `white`, older lines `grey`, a line starting with `✕` is `red`. Each line is a glyph, a space, a short clause in the pane voice: `▶ turn started`, `+ EXPLORE joins`, `✋ Allow Bash?`, `◆ skill code-review`, `◀◀ compacting context`, `■ turn done`.

Mount `Op1Crew.Log` with `lines`; only the last three show.
