The context ladder: a vertical stack of segments lit from the bottom, with a caption above.

`ladder-w` wide, segments `ladder-seg` tall at `ladder-pitch`, as many as fit in the header below the caption, at least 4. Lit segments are `green` up to 60% of the ladder, `orange` to 85%, `red` above; unlit are `dim`. The consumer passes a percent. One ladder is `CTX`, the context fill. Beside it belong the two rate-limit windows the engine reports, `5H` and `7D`, each its own ladder at the same pitch, so the header reads context, session budget and weekly budget in one glance, flush right.
