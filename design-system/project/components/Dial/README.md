A needle gauge for one tool channel: how many calls this session.

A `grey` arc from 200 to 340 degrees with five ticks, a `stroke-bold` needle and pivot dot in the channel colour, the reading in `dial-number` centred under the pivot, the label in `label` `grey` under that. Needles are relative: the busiest channel points full right and the others scale to it, so the consumer passes the value and the peak. Channels: `READ`, `EDIT`, `SHELL`, `WEB`, `AGENT`, `SKILL`, `MCP`, `OTHER`; a channel that has not been used has no dial. Up to 6 dials a row.

Mount `Op1Crew.Dial` with `label`, `value`, `peak` (the busiest channel's value) and `color`.
