# Claude Code plugins, mods, status lines and pets with retro / pixel / "little crew working" aesthetics

Research date: 2026-10-21. All GitHub metadata (stars, license, last push) was pulled live via `gh api repos/<owner>/<repo>` on this date unless noted. "Last push" is the repo's `pushed_at` field.

## Key Question 1: Are there Claude Code plugins/mods/skills that explicitly reference OP-1, Teenage Engineering, synth, tape deck, LCD, or pixel/sprite characters?

### Takeaway
No Claude Code project explicitly referencing the OP-1, Teenage Engineering, synthesizers, tape decks or LCD themes could be found anywhere (web search, GitHub repo search, GitHub code search, three mod directories). Pixel/sprite-character projects are abundant, however, and several of them render true-color pixel art inside the terminal using half-block or quadrant-block glyphs, which is exactly the technique an OP-1-style pane would need.

### Inferences
- Nobody has built the OP-1 aesthetic for Claude Code yet; the space is open. The closest aesthetic cousins are the retro arcade status line (claude-code-arcade), the half-block pixel pets, and Halloween Clawd's quadrant-glyph Raster.
- The three rendering tiers an OP-1 pane could borrow, in increasing fidelity: (1) multi-line ASCII/kaomoji frames (codachi, tamagotchi, /buddy); (2) half-block `▀`/quadrant-block true-color cells via `Raster` + `$.ui.blit` (nyan-cat, halloween, bad-apple, brainrot-break); (3) a custom pixel font mapped to a private Unicode block (claude-code-arcade), which gives real sprites but needs a font install.
- The OP-1's flat, four-color-per-screen palette and 1-bit-ish iconography map well to a `Raster` grid: the docs note a `Raster` "rounds each color to a smaller palette," so a deliberately limited palette will survive that quantization better than gradients.

### Gaps
- No repo, gist, or blog post referencing OP-1/Teenage Engineering/synth/tape/LCD aesthetics for Claude Code was found; the gap appears genuine rather than a search failure, given zero hits across four independent search surfaces.
- The GitHub repos behind the statuslin.es pet listings (Claude Pets, Pixipet, Pixel Cat, Familiar, Pixelband, Flow, Code Pet, Deck) could not be resolved with `gh search repos`; follow the statuslin.es pages for pinned-commit install links.

## Key Question 2: What Claude Code plugins visualize subagents, todos, tool calls, or "agents as characters"?

### Takeaway
There are two strong families: (a) browser/VS Code "pixel office" visualizers where each session or subagent is a character at a desk (pixel-agents at ~9.8k stars, claude-office, pixtuoid in-terminal, backstage, codemap), driven by Claude Code hooks or JSONL transcript tailing; and (b) native mods that draw subagent/todo/tool dashboards directly in a Claude Code pane (flightdeck, agenten-monitor, overseer, trace-waterfall, mission-control, agent-radar) using `agent.spawn`, `tool.call`, `turn.*` and `$.state`. Claude HUD (28.7k stars) is the dominant status-line approach for todos + agents.

### Inferences
- The mature "crew of little characters" implementations are browser canvases (pixel-agents, backstage, claude-office); the only in-terminal ones are pixtuoid (separate Rust TUI process) and the small mod-based pets (agent-theater, halloween, clawd-spinner), none of which show multiple subagents as distinct characters inside a Claude Code pane. An OP-1 pane that renders one tiny sprite per subagent would be new.
- The event plumbing is settled: for a mod, `agent.spawn` + `tool.call`/`tool.check` (with `e.agentId`) + `turn.*` + `$.agent.list()` status (`pending`/`running`/`waiting`/`idle`/`completed`/`failed`/`killed`); for an external process, settings hooks writing JSONL/SSE/Unix-socket events. flightdeck's reducer-plus-render split (`core.ts` / `register.tsx`) is a good structural template.
- agenten-monitor's todo-derived progress (reading `TodoWrite`/`TaskCreate`/`TaskUpdate` tool calls) is the practical way to get per-agent todo progress, since no dedicated "todo" event exists in the mods reference.

### Gaps
- No mod was found that draws subagents as individual animated sprites inside a Claude Code pane (as opposed to cards/lines); pixel-office projects all run outside the Claude Code TUI.
- Last-commit dates for flightdeck, mission-control, agent-radar, pin-memo, and the statuslin.es-listed pets were not confirmed beyond the directory listings.

## Key Question 3: Are there community "awesome" lists or plugin marketplaces listing UI/theme/visualization plugins?

## Key Question 4: Are there public examples of the newer Claude Code "mods" / function-hooks API (hooks modules exporting `register`, `ui.render` on a `Pane`, `$.ui.open`)?

### Takeaway
Yes, extensively. The official docs (interface, reference, gallery pages) publish complete worked examples, Anthropic ships four built-in mods in `anthropics/claude-code/mods/` with TypeScript declarations, and GitHub code search for `ui.render` in `register.js` returns 30+ repos. The API surface relevant to an OP-1 pane is: `hooks.json` with `"modules": ["./register.js"]`, `export function register(on)`, `on('ui.render', { component: 'Pane' }, ...)`, `$.ui.open`, `$.ui.resolve(e)` returning `Box/Text/Button/Input/Select/Raster/Image/Client/Svg`, `$.ui.invalidate`, `$.ui.blit`, `$.clock.every`, `$.state`/`$.store`.

### Cited Findings

#### Official documentation (primary source)
- Mod file layout: `.claude-plugin/plugin.json` (manifest), `hooks/hooks.json` with `"modules": ["./register.js"]`, and a hooks module that "Exports `register(on, options)`. Named `.js`, `.mjs`, `.cjs`, `.jsx`, `.ts`, `.mts`, `.cts`, or `.tsx`. An ES module."; optional `types/index.d.ts` for `$.state` — [Mods reference](https://code.claude.com/docs/en/plugins/mods/reference.md)
- The `hello-tabs` worked example (verbatim core):
  ```javascript
  on('command.run', { command: 'hello-tabs' }, async ($) => {
    await $.ui.open({ id: PANE, title: 'Hello tabs', focus: true, closeOnEscape: true })
    return {}
  })
  on('ui.render', { component: 'Pane' }, async ($, e, next) => {
    if (e.requestId !== PANE) return next(e)
    const { Box, Text, Button } = $.ui.resolve(e)
    const redraw = () => $.ui.invalidate('ui.render')
    ...
  })
  ```
  — [Draw in the interface with a mod](https://code.claude.com/docs/en/plugins/mods/interface.md)
- Render sites a mod can draw or replace: `Pane`, `AbovePrompt` (band), `UserMessage`, `AssistantMessage`, `ToolUse`, `ToolResult`, `ToolGroup`, `CommandOutput`, `AskUserQuestion`, `Spinner`, `ToolProgress`, `TurnDuration`, `InfoNotice`, `SessionMode`, `PromptHint`; "A pane is a sidebar beside the transcript in a wide fullscreen terminal, or a framed region above the prompt otherwise"; `$.ui.open` takes `id`, `title`, `focus`, `closeOnEscape`, `holdToasts`, `rows`, `columns` ("at most 45% of the terminal's width"); a pane opened by the mod itself (timer/`turn.start`) "appears only in a terminal at least 144 columns wide. - `Raster` element: "takes a `key`, its size in `columns` and `rows`, and `cells`, a base64 string that packs every cell. Each cell is three numbers: the character's code point, its color, and its background color. A color is a 24-bit RGB value in hexadecimal, such as `0xc62828` ... The value `0x01000000` ... means the terminal's default"; packing helper verbatim:
  ```javascript

    const numbers = rows.flat().flatMap(([char, color]) => [char.codePointAt(0), color, DEFAULT_COLOR])
    return new Uint8Array(Uint32Array.from(numbers).buffer).toBase64()
  }
  ```
  limits `columns` up to 512, `rows` up to 256; terminal only; "A `Raster` rounds each color to a smaller palette, so `0x2e7d32` draws as `#337733`" — [interface.md](https://code.claude.com/docs/en/plugins/mods/interface.md); [gallery.md](https://code.claude.com/docs/en/plugins/mods/gallery.md)
- Animation: "To animate a `Raster` that's already on screen, call `$.ui.blit` with the pane's `id` as `requestId`, the `Raster`'s `key`, the same size, and new cells ... It repaints that one element without running your `ui.render` hook again"; timers via `$.clock.every(1000, () => $.ui.invalidate('ui.render'))` in `session.start`; "`$.ui.invalidate('ui.render')` redraws — Throttled to 10 a second, or 30 in the terminal for the visible pane, the expanded band, and the hint line under the prompt. Calls that come sooner are coalesced." — [interface.md](https://code.claude.com/docs/en/plugins/mods/interface.md); [reference.md](https://code.claude.com/docs/en/plugins/mods/reference.md)

It reaches your hooks by posting data, which arrives as a `ui.message` event"; Terminal and Desktop only; failures raise `ui.fault` — [interface.md](https://code.claude.com/docs/en/plugins/mods/interface.md)
- `Image` element: "PNG or RGBA bytes up to 2 MiB, or a file path, `columns` and `rows` up to 255, and `alt` text"; draws as a picture only in kitty 0.28+, Ghostty, and iTerm2 3.5+ (iTerm2 requires Claude Code v2.1.305+ and fullscreen rendering); inside tmux/screen the `alt` text shows instead — [gallery.md](https://code.claude.com/docs/en/plugins/mods/gallery.md)
- `Text` props: `color`, `backgroundColor`, `bold`/`weight`, `italic`, `underline`, `dimColor`, `inverse`, `wrap`; "A `color` is a theme key or a color such as `'red'`"; `Box` border styles `single`, `double`, `round`, `bold`, `singleDouble`, `doubleSingle`, `classic`, `arrow`, `dashed`, `quote`; `Box` also takes `backgroundColor` — [reference.md](https://code.claude.com/docs/en/plugins/mods/reference.md)

### Inferences
- For an OP-1 display pane the recommended stack from these sources is: `$.ui.open({ id, columns })` from a `/op1` command (and optionally auto-open on `turn.start` when the terminal is ≥144 cols); a single keyed `Raster` using quadrant/half-block glyphs for the "screen"; `$.clock.every(80–150ms)` driving `$.ui.blit` for sprite animation (halloween uses 150 ms, ruvnet 80 ms, bad-apple 60 Hz); `$.state` atoms updated from `tool.call`/`agent.spawn`/`turn.*` reducers (flightdeck pattern) so the render hook stays pure; `$.store` for persistent settings; and an `e.surface !== 'terminal'` fallback to `Svg` (brainrot-break, agent-theater pattern) for Desktop/VS Code where `Raster` is unavailable.
- The 10/s (pane: 30/s) invalidate throttle means full-tree redraws cannot animate smoothly; every smooth-animation mod found bypasses it with `$.ui.blit`.
- `Image` would give true pixel sprites but is unusable in tmux and on non-kitty/Ghostty/iTerm2 terminals, so every shipped pixel mod chose block glyphs over `Image`.

### Gaps
- The `Client` element (own frame clock + pointer input) is documented but no public mod using it was found; ruvnet's guide flags it as "not used in the shipped mod."
- The exact contents of `mods/types/claude-code.d.ts` were not fetched; the docs say the GitHub copy "can be older than the Claude Code version you have installed."

## Key Question 5: Claude Code pet/companion/tamagotchi projects and their animation techniques

### Takeaway
